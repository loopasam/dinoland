# Runtime asset provenance

All raster art in this directory was generated with the built-in OpenAI image-generation tool for this project on 2026-08-12. Transparent cutouts were generated against a flat `#ff00ff` chroma background, converted locally to alpha PNGs, and optimized for browser delivery.

## Shared direction

Use case: `stylized-concept`. Polished hand-painted children's storybook illustration, soft gouache texture, rounded silhouettes, dark green-brown outlines, cheerful diffuse light from the upper left, no text, logos, or watermark.

## Files

- `nursery-background.jpg`: warm wooden dinosaur nursery, central woven nest, singing flowers at left, cloud decoration upper right, rounded cupboard at right, empty central play space.
- `egg.webp`: intact cream dinosaur egg with peach speckles and mint leaf markings.
- `baby-triceratops.webp`: mint baby triceratops, cream horns, peach belly, three-quarter pose facing right.
- `ball.webp`: stitched fabric ball in peach, sky blue, cream, and sage.
- `bath.webp`: oval cream-stone and honey-wood tub with pale blue water and leaf carvings.

Full prompt constraints and visual rules are recorded in `docs/art-guide.md`. Source-generation images remain in the local Codex generated-image store; only optimized runtime assets are committed.
